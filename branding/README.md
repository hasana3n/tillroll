# Tillroll brand

The Tillroll mark is a printing **T**: the crossbar is the print head, in signage amber, and the stem is the receipt
coming out of the slot below it, ending in a torn edge. It's the product's own action in one letter.

![Tillroll lockup](png/tillroll-lockup-dark-1200.png)

## Files

| File | Use it for |
|---|---|
| `tillroll-app-icon.svg` | App icon and avatars: the mark on a concourse-black rounded tile |
| `tillroll-app-icon-small.svg` | The same at 32 px and below (one deep notch, heavier head) |
| `tillroll-symbol.svg` | The mark alone on dark backgrounds (amber head, white paper) |
| `tillroll-symbol-light.svg` | The mark alone on light backgrounds (amber head, black paper) |
| `tillroll-symbol-black.svg` / `-white.svg` | One-colour versions for print, engraving or single-colour UI |
| `tillroll-symbol-small.svg` | The small-size cut of the mark alone |
| `tillroll-lockup-dark.svg` / `-light.svg` | Icon and wordmark side by side, for dark and light backgrounds |
| `tillroll-wordmark-dark.svg` / `-light.svg` | The name alone |
| `tillroll.ico` | Windows icon (16 to 256 px) |
| `png/` | Ready-made PNGs: app icon from 16 to 1024 px, the symbol, and both lockups |

All SVGs are pure paths (no fonts needed). The wordmark is Public Sans Bold, outlined, with the T and i tucked
together.

## Colours

| Name | Hex | Role |
|---|---|---|
| Concourse black | `#141416` | The tile and the app's ground |
| Signage amber | `#F2B33D` | The print head; in the app, selection and new arrivals only |
| Paper white | `#FFFFFF` | The receipt |
| Ink | `#F4F4F5` | Wordmark on dark backgrounds |

## Using the mark

- Leave clear space around it equal to the height of the print head on every side.
- Don't use it smaller than 16 px; below 32 px use the `-small` versions.
- Don't recolour the parts, add effects or shadows, rotate it, or stretch it.
- On busy or mid-tone backgrounds, use the app icon (the tile) rather than the bare symbol.

The mark and the name identify this project. You're welcome to use them to refer to Tillroll, for example in an
article or a list of tools, but not in a way that suggests your project or product is Tillroll or is endorsed by it.
